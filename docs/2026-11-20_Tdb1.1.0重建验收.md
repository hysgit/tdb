# Tdb 1.1.0 重建与验收

本轮按当前用户录屏重建五栏与独立播放器，修复 Wi-Fi 的地址选择与上传流程。原版完整源码没有恢复，在线听力服务和未演示流程也不作完成声明。

## 依据

- 当前录屏及原资源包的证据与哈希：[当前录屏与资源解密依据](2026-11-20_当前录屏与资源解密依据.md)。录屏和帧图仅保留本地忽略目录，没有推送到公开仓库。
- 文件根目录、播放器、更多与我的按当前录屏核对；录音详情、转换详情等未展示部分使用独立实现。
- `fs.zip` 解密成功不代表 FairPlay 主程序解密成功。主程序仍有 `cryptid=1`，没有恢复原在线听力服务器接口。

## 本地验证

| 检查 | 结果 | 边界 |
|---|---|---|
| 完整 Flutter 静态检查 | No issues found | 不替代 Swift 编译 |
| 合并回归测试 | 174 通过、1 跳过 | 跳过项为 Windows 无目录符号链接创建权限；随后补充的活动文件检查另有定向测试 |
| 主界面流程 | 五栏、直属文件夹、播放器推入/返回、批量移动/删除与导入页通过 | 使用受控音频及存储替身；不是 iPhone 实际录音验证 |
| 资料库与仓库 | 联合 25 通过、1 跳过 | 覆盖保存队列、失败回滚、并发字幕关联、录音引用及活动文件保护 |
| MP3 编码 | ffprobe 实际确认编码/声道/采样率/码率/时长 | 原生音轨读取、M4A 与极端速度音质待实机 |
| 真实 LAN | 浏览器可打开实际 LAN 根地址；HTTP PUT 音频及独立字幕均 200，落盘 SHA-256 与输入一致 | 本机运行真实 Dart HTTP 服务及独立磁盘账本，不是 iPhone 网络；浏览器选文件受扩展文件访问权限限制 |
| 页面渲染 | 320 与 390 宽度公开示例预览通过 | 系统状态栏、私有媒体内容没有仿造；图像仅存本地 |

可复现命令：

```powershell
flutter pub get
flutter analyze
flutter test
flutter test scripts/render_current_home_test.dart
flutter test scripts/render_current_player_test.dart
dart run scripts/wifi_browser_fixture.dart
```

Wi-Fi Fixture 使用独立 `dist/wifi-browser-smoke` 目录，退出后停止监听。本次本地证据 `http-verification.json` 已保留，监听已关闭。

## 云端与真机门槛

- GitHub Actions 同一源码分别执行 iOS 无签名编译与模拟器 LAN/真实波形探针。探针结果需以本次云日志为准，不能把新增脚本视为已经运行成功。
- Codemagic 使用现有 Tdb 应用、`com.hysgit.tdb`、App Store 描述文件与现有内测组。上传完成、Apple 处理完成、TestFlight Testing 分别验证。
- 实际 iPhone Wi-Fi 上传页可达性、局域网权限、后台音频、中断恢复、麦克风、离线识别和转换音质仍需手机验收。
- 在线听力目录、云同步、播客及原版精听训练协议尚未恢复；不使用伪造目录、下载 URL 或成功提示填补。

发布结果将在云检查完成后补充到本文件。
